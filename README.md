# LDR-Automatic-Street-Light-Physics-Project

This project is an automatic street-light system that uses an LDR (Light Dependent Sensor) sensor to detect ambient light intensity and control an LED. The LED automatically switches ON in low-light conditions and OFF when there is sufficient light. It demonstrates a simple application of sensor-based lighting and energy efficiency.

I developed and assembled the project using resources from my school laboratory (ATL Lab), with guidance from my Physics teacher. In the development process, one particular challenge I faced was acquiring a battery of suitable voltage compatible with the solar photovoltaic panel. Therefore, I used an Arduino Uno as an alternative power source while testing the circuit.

One of the reasons I developed this project was because I wanted to explore how technology and energy can be used efficiently
while serving a meaningful practical purpose.
